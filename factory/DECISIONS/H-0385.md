- Why: the position arms already refuse on everything git can answer about a tree — dirty,
  ahead, not-ff-only — and all of them were right, 22 times, about a tree nobody was supervising
  (#489's reflog). The missing precondition is not a property of the tree; it is the relation
  between the tree and the pass. A pass knows that relation through exactly one name,
  `$FACTORY_ROOT`, so the gate is that equality — but it speaks only about trees it can read:
  an installed tree that does not resolve stays the position read's `SUPERVISOR-UNKNOWN`
  sentence and touches no streak, because #342's blind-activation contract says unknown counts
  are not refusals (measured on the first gate: a chmod-000 installed tree tallied through this
  gate and the leg that refuses exactly that streaked to 5 in one pass — the suite caught my
  fail-closed-on-everything version in the one arm where silence is the contract); an
  unreadable `$FACTORY_ROOT` still refuses a tree that does resolve, because a pass cannot
  prove ownership of what it cannot see. It sits after the position read, not before it: a
  tree git cannot count must stay silent and unstreaked -- #342's blind-activation contract
  says an unknown count is not a refusal, and my first placement, run before position, tallied
  exactly the ghost directory that contract names (measured twice: the r342 blind leg streaked
  to 5 with the gate before position, and again with the gate merely skipping unresolvable
  paths, because the ghost is fully readable and only uncountable; the position read is the
  arm that can tell those two trees apart, so the gate stands where it can see that answer).
  A foreign tree is refused before any tally, dirty, merge or `DRY-RUN` line that would
  promise a merge the gate vetoes.
- What it cost: the arm now repairs only the checkout it runs in. An operator who intends to
  supervise from a different tree than the installed one — a worktree pointed at the deployed
  checkout — loses the automatic repair for it and gets the named refusal instead; that merge
  is a deliberate act again, and the sentence says which tree it declined.

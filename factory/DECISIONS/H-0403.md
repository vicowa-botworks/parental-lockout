  and a percent means the same thing on every one: `MemoryHigh=25%` is 84x the observed peak, so
  reclaim pressure can only ever be felt by a runaway and never by a legitimate pass, and
  `MemoryMax=50%` lets the kernel kill the biggest thing inside the fence before this workstation
  starts host-wide reclaim. `MemorySwapMax` was left unset because `SwapTotal` is 524 MB — a
  swap-shape policy cannot exist on a machine with no swap, and inventing one tests nothing. The
  refusals are measurements too, not taste. `PrivateTmp=` and the namespace directives were
  refused because the harness rendezvouses on the host `/tmp` as a documented convention — every
  dispatched unit's brief names a `/tmp/plock-*` scratch (this unit's is
  `/tmp/plock-unclaimed-476-3hcqEg`), and the tooling writes host-`/tmp` files an activation
  reads across boundaries (this session's own harness writes under `/tmp/opencode-*` and shells
  out to host tools that read them); `PrivateTmp=` mounts a fresh tmpfs per activation, so the
  breakage is silent blindness, and #873's rule — decode ambiguity must resolve toward the
  lockout, never toward the quiet path — argues against shipping a directive whose failure mode
  is a weirdly-red tick instead of a fence. `Delegate=` inverts the measured #390 posture: today
  the teardown of the 18-of-18 Wine grandchildren is done by systemd's cgroup teardown
  unconditionally (`KillMode=control-group` is the default the fence left in place), and
  delegation hands that job to harness code that can itself become the grandchild that does not
  die — the exact shape #246 measured at 1 h 07 min of queue freeze. `CPUQuota=` trades the fence
